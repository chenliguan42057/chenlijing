# AI 助手修复方案 B · 落地操作手册

> 把 AI 对话从「Cloudflare Worker + Workers AI」切换到「**腾讯云 CloudBase 云函数 + 智谱 GLM-4-Flash（永久免费）**」，解决 workers.dev 在国内网络连不上的问题。

## 新架构（前端零密钥，保持不变）

```
浏览器(你的网站)  →  https://<你的环境>.service.tcloudbase.com/chat  →  智谱 GLM-4-Flash(免费)
                         （云函数，密钥在此环境变量中）
```

- 前端代码 `ai.js` **一行都不用改**，只改 `js/config.js` 里的 `WORKER_URL`。
- 智谱 API Key（机密）只存在云函数环境变量里，绝不进前端/仓库。

---

## 第 1 步 · 申请智谱 API Key（约 3 分钟，免费）

1. 浏览器打开 **https://open.bigmodel.cn**（智谱 AI 开放平台）。
2. 用**手机号**注册并登录。
3. 左侧菜单点 **「API Keys」** → 点 **「创建 API Key」**。
4. 复制生成的 Key（形如 `xxxxxxxx.xxxxxxxxxxxxxxxx`），**先存到记事本**，下一步要用。
   - 说明：`glm-4-flash` 模型**永久免费、不限调用量**，无需充值。

---

## 第 2 步 · 注册腾讯云并开通 CloudBase（约 5 分钟，免费）

1. 打开 **https://cloud.tencent.com** → 手机号注册 → 完成**个人实名认证**（需身份证+人脸，腾讯云必须）。
2. 搜索进入 **「云开发 CloudBase」** → 点 **「立即使用 / 开通」**（选**免费套餐/按量付费**即可，个人用量几乎不产生费用）。
3. 创建**环境**：环境名称填 `mint-ai`（或任意），地域选默认（上海/广州均可），等待创建完成（约 1 分钟）。

---

## 第 3 步 · 创建云函数并粘贴代码（约 5 分钟）

1. 进入你的 CloudBase 环境 → 左侧 **「云函数」** → **「新建云函数」**。
2. 名称填 `zhipu-proxy`，运行环境选 **Node.js 18.13**（或 Nodejs18），创建方式选「**空白函数/从模板**」皆可。
3. 把本目录 **`index.js` 的全部内容**复制，**覆盖**编辑器里的默认代码。
4. 点 **「保存并部署」**（云端安装依赖可跳过，本函数无第三方依赖）。

---

## 第 4 步 · 配置环境变量（智谱 Key）

1. 在云函数 `zhipu-proxy` 详情页 → **「配置」/「函数配置」** → 找到 **环境变量**。
2. 添加：
   - 变量名：`ZHIPU_API_KEY`
   - 变量值：粘贴第 1 步复制的智谱 Key
3. 保存后**重新部署一次**（让环境变量生效）。

---

## 第 5 步 · 开启 HTTP 访问服务（拿域名）

1. 云函数 `zhipu-proxy` 详情页 → **「HTTP 访问服务」/「触发管理」** → 点 **「启用」**。
2. 系统会生成一个默认域名，形如：
   ```
   https://zhipu-proxy-xxxxxx-123456.service.tcloudbase.com
   ```
3. 复制这个域名。
4. **先验证**：浏览器直接打开该域名，应显示：
   `{"ok":true,"msg":"薄荷减脂 AI 代理运行中（智谱 GLM-4-Flash）"}`

---

## 第 6 步 · 改前端配置并推送（自动同步两站）

1. 把该域名填进仓库根目录 **`js/config.js`**：
   ```js
   WORKER_URL: "https://zhipu-proxy-xxxxxx-123456.service.tcloudbase.com",
   ```
2. 保存后 `git commit` + `git push` 到 `chenlijing` 的 `main` 分支
   （已配置的自动同步工作流会把它同步到 `chenlixia`，两个网站同时生效）。
3. 等 1~2 分钟，刷新网站 → 进「AI 助手」页发消息测试。

---

## 常见问题排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 浏览器打开域名报 404/无响应 | HTTP 访问服务未启用或域名不对 | 回到第 5 步确认启用并复制完整域名 |
| 网页提示「网络不佳」 | config.js 的地址没填/填错/未重新推送 | 检查 WORKER_URL，重新 push 并等 1-2 分钟 |
| 提示「小助手暂时有点忙」 | 智谱 Key 无效或未配置 | 检查第 4 步环境变量 ZHIPU_API_KEY 是否填对并重新部署 |
| 提示「额度用完啦」 | 智谱限流（免费模型一般不会触发） | 稍后重试；如持续，去智谱控制台查看用量 |
| 提示「连接小助手失败」 | 云函数返回了非预期错误 | 浏览器直接访问域名看健康检查输出 |

## 安全说明

- 智谱 API Key 仅存在于云函数**环境变量**（腾讯云加密存储），不出现在任何前端文件/仓库/网页源码中，维持「前端零密钥」红线。
- 免费额度：CloudBase 个人环境每月有免费云函数调用额度，日常打卡对话完全够用；智谱 glm-4-flash 本身永久免费。
- 若之后不想用智谱，同一云函数可改 `MODEL` 与请求地址，换成硅基流动 / 通义千问等（同样保持密钥在环境变量）。
